# 历史阶段记录

[项目首页](../README.md) · [当前版本结果](../docs/releases/2026-09-16/README.md)

本目录保留早期研究的阶段验收与来源校验。它用于追溯设计和检查过程，不是当前正式版本的成绩入口。

## 阅读方式

| 目录前缀 | 所属阶段 |
| --- | --- |
| `p0_…p7_…` | 早期 Requirement Grounding 与运行环境实验 |
| `sqlg_v1_sg…` | SQL Grounding V1 的分阶段实现与验收 |
| `sqlg_r2_stage…` | 启动取证、主流程、提交修复及 P2 生命周期研究 |
| `sqlg_v13…` | 该时期的 SQL Grounding 合同与 schema 输入研究 |

每个子目录的 README 和 summary 说明当时的范围。旧记录中的 PASS 只适用于对应代码、输入与检查，不代表该功能仍然开启，也不能与当前 Full600 汇总直接混算。

本次整理不重写或搬动历史记录，避免破坏已有哈希清单和文件引用。新版本的公开汇总放在 `docs/releases/`；不要继续向此目录添加完整模型输出、数据库或私有运行日志。
