# 当前版本与核心结果

本目录保存现阶段代码的发布说明及同题 600 题核心结果。材料于 2026-09-16 整理，2026-09-17 完成发布前检查。相对已评测源码，本次只修复 P2 多阶段审计记录的存储限制；没有重新运行评测，成绩仍对应修复前的冻结版本。

## 方法概述

系统在生成 SQL 前，先整理四类信息：相关表、表之间的连接关系、用户概念对应的字段、任务需要的业务知识。Check 检查这些信息是否足以执行任务，必要时补查官方工具或向用户澄清。Gate 决定是否重新整理信息；重做先在草稿中进行，通过检查后才更新正式状态。

Main 根据用户请求和整理后的信息编写、执行并提交 SQL。主流程未完成任务时，在预算和运行条件允许的情况下启动官方 fallback agent。四维信息不是正确性的保证：字段选择错误、业务条件遗漏和后续 SQL 推理仍可能导致失败。

本次整理不调整 Prompt、工具、预算、路由或 fallback 输入，也不重新启用已回滚的实验。

## 同题 600 题结果

评测采用 BIRD-Interact Full 的同一组 600 题，模式为 a-interact，运行配置为 `leaderboard`，主模型为 `glm-5.2`。P1 表示第一阶段通过，Full 表示两个阶段均通过。

| 指标 | 原基线 | 当前版本 | 变化 |
| --- | ---: | ---: | ---: |
| P1 通过 | 144 / 600（24.00%） | 150 / 600（25.00%） | +6 题 |
| Full 通过 | 79 / 600（13.17%） | 75 / 600（12.50%） | −4 题 |
| Reward | 124.5 | 127.5 | +3.0 |
| 输入 token | 74,548,984 | 79,026,960 | +6.01% |
| 输出 token | 7,723,158 | 24,231,520 | +213.75% |
| 总 token | 82,272,142 | 103,258,480 | +25.51% |

Reward 按 `0.7 × P1 通过数 + 0.3 × Full 通过数` 统计。这里的改善很有限：P1 和 Reward 上升，但 Full 下降，不能据此宣称整体能力全面超过基线。

逐题配对后，47 题成绩提高、47 题下降、506 题不变。P1 新通过 40 题、失去 34 题；Full 新通过 24 题、失去 28 题。这些是不同统计口径，不能相加作为新增能力的题数。

主流程取得 P1 通过 84 题、Full 通过 42 题。Fallback 共触发 377 题，新增 P1 通过 66 题、Full 通过 33 题。最终成绩包含 fallback 的贡献，不等于四维流程单独取得的成绩。

## Token 口径与限制

当前版本的总 token 包括 Grounding、Main/fallback 和用户模拟器：

| 部分 | 输入 token | 输出 token | 总 token |
| --- | ---: | ---: | ---: |
| Grounding | 31,865,394 | 16,262,272 | 48,127,666 |
| Main 与 fallback | 43,820,551 | 7,779,642 | 51,600,193 |
| 用户模拟器 | 3,341,015 | 189,606 | 3,530,621 |
| 合计 | 79,026,960 | 24,231,520 | 103,258,480 |

旧汇总遗漏了 Grounding 的 48,127,666 token，因此“总 token 降低”的旧结论不再采用。Reasoning token 已计入输出，不重复相加；cached token 是输入中的缓存部分，也不额外相加。

上述数值是最终计分轨迹中已报告的用量，不是整个研究项目的消耗。600 题中有 18 题采用经授权的替代运行；被替代的尝试和开发实验不计入此表。另有 20 次 Grounding 尝试没有报告用量，不能按零成本理解。模型、输入/输出单价和缓存计费不同，也不能直接用总 token 比例推算金额。

本报告未对全部 600 题逐一进行语义复核，benchmark PASS 不保证完整业务语义正确；单轮同题比较也不构成统计显著性结论。

## 发布检查

2026-09-16 初检为 440 通过、156 条失败记录（含子测试）、4 跳过、1 个收集错误。经批准同步过期测试、归档两份退役实验的措辞断言后，剩余两项失败定位到 P2 审计存储，而非语义决策。

2026-09-17 经单独授权修复后，全套离线测试为 **513 通过、0 失败、5 跳过**，另有 315 个子测试通过。新增测试覆盖无损保存、逐阶段大小限制、异常数据、UTF-8 字节计数和记录条数上限。

五项跳过包括原有四个旧 Clarification 测试，以及缺少历史 P7 依赖的 SG7 评测测试；它们不计为通过。

仅含拟发布文件、没有本地数据集的副本另行验证为 **511 通过、0 失败、7 跳过**。多出的两项跳过是依赖 Full600 输入及知识库的源数据完整性检查；安装对应数据后才执行，并非功能测试被忽略。

原失败中，P2 合并记录为 4,100 / 4,112 字节，超过单条 4,096 字节限制。修复将外层摘要与最多四个阶段分别限为 4,096 字节，整条工具记录仍限为 24,832 字节，最多保存 64 条；数据格式不变，不截断内容。它不修改 Prompt、工具、预算、路由和四维状态。详细证据见 [test_migration.md](test_migration.md)。
